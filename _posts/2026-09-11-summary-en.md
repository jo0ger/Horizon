## [OpenAI launches GPT-Live-1 on its API](https://openai.com/index/introducing-gpt-live-1-in-the-api/) ⭐️ 9.0/10

OpenAI launched GPT-Live-1, a full-duplex simultaneous speech-and-listening model, to its developer API on September 10, 2026. It outperforms the previous generation GPT-Realtime-2.1 by 30% on the Full Duplex Bench benchmark, and is priced at $0.05 per minute for API access to the front-end voice layer. This launch advances the development of low-latency real-time voice AI applications, enabling developers to build more natural interactive voice agents for use cases like customer service, language learning and telephone-based services. It marks a major step forward in the commercialization of full-duplex speech AI, benefiting both developers and end users. GPT-Live-1 integrates speech understanding and output into a single model, eliminating the latency caused by multiple handoffs between separate speech-to-text, LLM, and text-to-speech components; it also supports natural interruption, background noise processing, long-form dialogue, and can offload complex reasoning and tool use to backend models. Early adopters have reported significant improvements in user experience and development efficiency, such as an 80% reduction in false interruptions for a language learning platform, and an 80% reduction in code volume for a medical service platform.

telegram · AI_News_CN · Sep 11, 03:17

**Background**: Full-duplex speech refers to the capability of a spoken dialogue system to simultaneously understand incoming speech while producing speech output, which enables more natural conversational behaviors like interruption, overlapping dialogue and dynamic turn-taking compared to older half-duplex systems that can only listen or speak at one time. Full Duplex Bench is an open, standardized benchmarking framework for evaluating the interactive conversational capabilities of full-duplex spoken language models, focusing on metrics related to pause handling, interruption management, turn-taking and task performance in multi-turn dialogue.

## [Trynix.dev runs any Nix package in your browser](https://simonwillison.net/2026/Sep/10/trynix/) ⭐️ 8.0/10

Farid Zakaria launched trynix.dev, a WebAssembly-powered service that lets users run any Nix package from the past 13 years directly in the browser. It also supports a GitHub action that lets users boot and test pull request builds directly in the browser without any server infrastructure. This tool eliminates the need for local environment setup when testing specific versions of Nix packages or pull request builds, making it easier for developers to quickly test code. It also demonstrates a novel combination of Nix package management, WebAssembly, and in-browser virtualization that expands the capabilities of browser-based development tools. Trynix.dev uses the qemu-wasm project to run a full x86_64 Linux virtual machine entirely in the browser via WebAssembly. Any available Nix package can be loaded by specifying it via a URL parameter, and users get an interactive shell to work with the package after clicking the Load button.

rss · Simon Willison · Sep 10, 23:44

**Background**: Nix is a purely functional cross-platform package manager that enables reproducible package builds and keeps different package versions isolated from each other. QEMU is a popular open-source machine emulator and full-system virtualizer that supports running entire operating systems on top of a host system, and qemu-wasm is an experimental port of QEMU compiled to WebAssembly that allows it to run inside web browsers.
