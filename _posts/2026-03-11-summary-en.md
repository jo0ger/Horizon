## [Google Releases Gemini Embedding 2 Multimodal Model](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-embedding-2/) ⭐️ 8.0/10

Google has released the public preview of Gemini Embedding 2, its first native multimodal embedding model, which is available via Gemini API and Vertex AI. The model maps multiple content types including text, images, video, audio and documents into a unified vector space for RAG and semantic retrieval tasks. This release simplifies multimodal RAG development pipelines by removing the need to combine multiple separate embedding models for different content types, bringing great benefits to AI practitioners building multimodal retrieval applications. It also pushes forward the industry trend of unified native multimodal processing for common AI workflows. Gemini Embedding 2 supports over 100 languages, accepts up to 8192 tokens per input, can process up to 6 images, 120 seconds of video or 6 pages of PDF directly, and supports interleaved mixed input of different content types. It outputs a default 3072-dimensional vector that can be reduced on demand, and is compatible with common AI toolchains like LangChain.

**Background**: Embedding models convert different types of content into numerical vectors that can be compared for semantic similarity, which forms the foundation of semantic search and retrieval tasks. Retrieval Augmented Generation (RAG) is a widely used AI framework that improves large language model outputs by retrieving relevant external knowledge before generation, making responses more accurate and up-to-date. A native multimodal embedding model can process multiple content types within a single model and map all content to the same shared vector space, unlike traditional solutions that combine multiple separate unimodal models.
