## [California to exempt open source OS from age verification](https://t.me/zaihuapd/43499) ⭐️ 7.0/10

Submitted on May 18, amendment AB 1856 to California's AB 1043 Digital Age Assurance Act would redefine 'operating system provider' to exempt fully open source operating systems like Debian and Ubuntu from mandatory age verification rules. The amendment is scheduled for a vote in June 2026, before the original AB 1043 law takes effect in January 2027. This amendment removes an unreasonable regulatory burden that would have forced volunteer-driven open source projects to implement costly age verification systems. It protects the open source software ecosystem while still keeping commercially oriented platforms with proprietary app stores subject to the law, balancing youth protection and open source development needs. Commercially focused platforms such as SteamOS, which ships with a proprietary app store by default, will still likely fall under the mandatory age verification requirements of the original law even if the amendment passes. AB 1043 is currently scheduled to enter into force on January 1, 2027.

## [OpenAI Codex tests new context window scheme](https://github.com/openai/codex/pull/27488) ⭐️ 7.0/10

OpenAI is testing a new context window management scheme for its Codex AI coding agent that replaces traditional summary-based compression with creating new windows when the token limit is hit. The new scheme adds history recall capabilities to let the model retrieve previous content and avoid interrupting ongoing tasks, and it is still in active development and not yet officially launched. This new scheme solves two well-known pain points of the original summary-based compression method: unnecessary token waste and accidental loss of important details, which can improve the performance of Codex on long-running coding tasks. This development also introduces a novel approach to context window management that could influence future optimization work for other large language model systems. Under the new scheme, both manual and automatic context cleanup follow the new window creation workflow, and no new summaries are generated at all when switching to a new window. The feature is currently being developed across three active GitHub pull requests: #27488, #29743, and #39827.

telegram · AI_News_CN · Aug 31, 00:14

**Background**: OpenAI Codex is a suite of AI-powered coding agents developed by OpenAI to automate common software engineering tasks such as writing code and fixing bugs. Context window management is the practice of optimizing the input given to a large language model to make full use of its limited token budget, which is the maximum number of input and output tokens the model can process in a single generation. The traditional approach to handling full context windows is to compress conversation history into a summary to free up tokens, but this method consumes extra tokens and often loses critical details from the original history.
