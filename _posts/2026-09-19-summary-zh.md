## [OpenAI Agent API 超额计费问题调查](https://status.openai.com//incidents/01M2VA7X37P1ASADSNZ1CG4N4D) ⭐️ 7.0/10

OpenAI 目前正在调查 Agent API 中 OpenAI 托管容器导致超额收费的问题，并且正在为受影响的用户准备退款。 该问题直接影响在 Agent API 中使用 OpenAI 托管容器的开发者和企业的财务成本，需要用户检查自己的账单是否存在意外超额收费。 Agent API 的 OpenAI 托管沙箱按照标准容器费率计费，和 OpenAI 的 Hosted Shell 以及 Code Interpreter 服务费率一致。目前该问题仍在调查中，开发团队正在修复。

telegram · AI_News_CN · Sep 18, 22:36

**背景**: OpenAI Agent API 是为开发者管理智能体底层基础设施的服务，让开发者可以不用处理基础设施维护直接构建 AI 智能体。OpenAI 托管容器为开发者提供了预配置的 Linux 沙箱环境，内置常用开发工具，按照容器使用时长计费。
