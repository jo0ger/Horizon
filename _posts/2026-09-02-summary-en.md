## [Virtualizor update infrastructure hit by BGP hijacking](https://www.virtualizor.com/blog/security-incident-bgp-hijacking/) ⭐️ 8.0/10

Between August 28 and 30, 2026, Virtualizor's update infrastructure suffered a BGP hijacking attack where attackers used valid TLS certificates to distribute malicious updates that installed a root backdoor on target systems. Only a small number of users who updated during this window were confirmed compromised, and there is no evidence that other Softaculous products were affected. This incident demonstrates the security risk of BGP hijacking as a sophisticated supply chain attack targeting widely used virtualization infrastructure, and it serves as a critical warning for infrastructure administrators running Virtualizor to check their systems for compromise. The official confirms this is not a software code vulnerability in Virtualizor, but a compromise of the update distribution path; the malicious payload adds a root SSH key, installs Java code, and sets up a persistent service, with one hosting provider finding 5 out of 34 affected hypervisors.

telegram · zaihuapd · Sep 1, 06:05

**Background**: Virtualizor is a widely used web-based VPS control panel developed by Softaculous that helps administrators manage virtual private servers and virtualization resources. BGP hijacking is an attack that corrupts global internet routing tables to redirect traffic meant for a target service to attacker-controlled servers by injecting false route advertisements. A root backdoor is malicious code that grants attackers full root privileged access to a compromised system.

This API change directly addresses the growing risk of industrial-scale distillation attacks that steal capabilities from leading frontier LLMs, while Amodei's stance clarifies industry positions on open-weight models and geopolitically charged AI regulation debates.
