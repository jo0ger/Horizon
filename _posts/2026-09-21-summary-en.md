Former npm CEO Laurie Voss published a proposal that major software package registries including npm, PyPI, and Docker Hub charge enterprise users for open source package access, then distribute a fixed proportion of the revenue to open source maintainers proportional to their usage in enterprise dependency trees, while keeping access free for individual developers and open source projects. This proposal addresses the long-standing open source sustainability problem where most maintainers work unpaid despite enterprises deriving massive commercial value from open source, offering a concrete model that could redirect existing enterprise spending on open source tooling directly to the people who write and maintain the code. The proposal does not change open source licenses or rely on donations, and only requires adding a new line item to existing registry billing for enterprise customers. Voss notes that 60% of open source maintainers currently work for no compensation, while enterprises already spend billions of dollars annually on open source supply chain security.

A dependency tree maps all direct and indirect open source packages that an application relies on, showing which packages depend on which other packages.

## [StepFun releases 600B Step 5 open-source MoE LLM](https://telegra.ph/%E9%98%B6%E8%B7%83%E7%94%A9%E5%87%BA-Step-5-Preview600B-%E7%A8%80%E7%96%8F-MoE-%E5%8F%AA%E6%BF%80%E6%B4%BB-27B%E6%8A%8A%E5%BC%80%E6%BA%90%E6%97%97%E8%88%B0%E7%9A%84%E6%80%A7%E4%BB%B7%E6%AF%94%E8%BE%B9%E7%95%8C%E5%BE%80%E5%A4%96%E6%8E%A8%E4%BA%86%E4%B8%80%E6%A0%BC-09-21) ⭐️ 9.0/10

Chinese AI lab StepFun released a preview of its new open-source flagship large language model Step 5 on September 18, 2026. Step 5 is a 600 billion parameter sparse Mixture-of-Experts model that only activates 27 billion parameters during inference, which improves the cost-performance of current open-source flagship LLMs. This new model pushes the cost-performance boundary of open-source large language models, making frontier-level large language model capabilities more accessible to developers and users at a lower inference cost. It aligns with the broader industry trend of adopting sparse Mixture-of-Experts architecture to efficiently scale large language models. Step 5 scored 44 on the Artificial Analysis Intelligence Index v4.3.2 at an inference cost of around $0.71. The sparse MoE architecture allows it to have a large total parameter count for strong capabilities while keeping inference costs low by only activating a small subset of parameters per token.

telegram · AI_News_CN · Sep 21, 01:59

**Background**: Sparse Mixture-of-Experts (MoE) is a neural network architecture for large language models that splits the model into multiple smaller expert sub-networks. Instead of activating all parameters for every input token like a dense model, MoE models only activate a small number of experts for each token, which allows them to have large total parameter sizes while keeping inference costs low. This architecture has become a mainstream approach for building extremely large-scale and cost-effective large language models.

This project demonstrates that large-scale AI-assisted code migration can deliver dramatic performance and memory improvements for production software, setting a precedent for future language migration projects in the software engineering industry. It also highlights the practical value of AI agents in large-scale software development work. The project was completed incrementally by updating runtime modules one by one, with 135 releases and an average of 1.3 pull requests per day. Benchmark results show that the original TypeScript implementation handled 7.55 one-turn session lifecycles per second compared to 120 per second for Rust, and a 10-client agent test consumed 1383 MB of memory for TypeScript versus only 126 MB for Rust.

Token fees are the standard pricing model for AI inference, where customers are charged based on the amount of AI model processing they use, with each token representing roughly four characters of input or output text.
