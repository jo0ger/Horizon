GDN and QSA are a hybrid attention mechanism developed by the Qwen team, where Gated DeltaNet (GDN) compresses past context efficiently and Qwen Sparse Attention (QSA) selects relevant context to keep long-sequence processing costs low.

This release adds extensive performance and memory optimizations for Kimi-K3 and DeepSeek V4 models, expands ROCm hardware support, and introduces multiple new features like tiered KV cache disk offloading and a Rust gRPC frontend. As one of the most widely used open-source LLM inference engines, this release delivers significant performance and memory improvements for popular modern LLMs and expands compatibility with AMD GPUs, which lowers deployment cost and expands hardware choice for open LLM inference and serving. Pre-built wheels and Docker images are provided for multiple CUDA versions, ROCm, CPU, and XPU platforms.

## [Asahi Linux 7.2 adds M3 USB 3/Thunderbolt](https://asahilinux.org/2026/08/progress-report-7-2/) ⭐️ 8.0/10

The Asahi Linux project's Linux 7.2 progress report announces that the SPMI interface and ACE3 USB-C controller have been successfully brought up for Apple M3 series chips. This enables full USB 3.0 and Thunderbolt functionality for all M3 series Apple Silicon Macs running Asahi Linux. This is a major milestone for the Asahi Linux project, which ports native Linux to reverse-engineered, undocumented Apple Silicon hardware. It expands the usability of Linux on modern Apple Silicon laptops, giving users a fully functional open source alternative to macOS. Contributors found that the M3's ACE3 controller has nearly the same register layout as the older CD3217 controller, differing only in that it communicates via the SPMI bus rather than I2C. Reverse engineering work done by contributors mildsunrise and chaos_princess was critical to enabling this new support.

hackernews · pizzaiolo · Aug 26, 22:35

**Background**: Asahi Linux is a community-led project that ports the Linux kernel and desktop software to Apple Silicon-powered Macs, relying entirely on reverse engineering since Apple does not release public hardware documentation for its custom chips. SPMI, short for System Power Management Interface, is a high-speed low-latency serial bus used for power and component control in modern SoCs. ACE3 is Apple's custom USB-C controller for M3 series chips that handles USB functionality, power delivery, and internal bus access.

## [Google upgrades Gemini Live with Spark agent](https://telegra.ph/Google%E5%8D%87%E7%BA%A7Gemini-Live%E5%BC%95%E5%85%A5Spark%E6%99%BA%E8%83%BD%E4%BB%A3%E7%90%86%E4%B8%8E%E8%87%AA%E5%8A%A8%E6%93%8D%E4%BD%9CGmail%E7%AD%89%E5%8A%9F%E8%83%BD-08-27) ⭐️ 7.0/10

Google has upgraded its Gemini Live conversational voice AI feature to add the Spark intelligent agent and the ability to automatically operate Google services such as Gmail. This update expands the autonomous functionality of Gemini Live beyond basic conversational interaction. This update follows the current AI industry trend of developing agentic autonomous AI, expanding the real-world practical use cases of conversational generative AI and deepening Google Gemini's integration into the Google service ecosystem. It brings Google's generative AI platform closer to fully autonomous daily task assistance for end users. The new features add automation for Google-owned services such as Gmail, allowing the Spark agent to complete specified tasks on the user's behalf within these services without manual user input. This update focuses on enhancing the agentic autonomous capabilities of the Gemini platform, which has been a core focus of Google's 2025 Gemini updates.

telegram · AI_News_CN · Aug 27, 06:09

**Background**: Gemini is Google's flagship generative AI large language model family and virtual assistant platform, which replaced Google's earlier Bard and Duet AI brands in 2024. Gemini Live is a dedicated voice conversation feature of Gemini that allows users to have natural back-and-forth voice chats with the AI instead of typing prompts. Intelligent AI agents are autonomous AI systems that can independently complete multi-step tasks and take actions on behalf of users without continuous manual guidance.
