## [Reladraw: Open-source diagram language with manual positioning](https://github.com/reladraw/reladraw) ⭐️ 8.0/10

A new open-source diagram language called Reladraw has been released, which combines text-based diagram definition with manual control over element positioning. It is designed to be usable by both humans and AI agents, and includes an online playground for testing without installation as well as an agent skill for use with Claude and other AI tools. It solves a long-standing pain point in diagramming by bridging the gap between rigid auto-placement tools that lack layout control and time-consuming drag-and-drop tools that are inefficient for AI agents to manipulate. This fills a need for diagramming in the current trend of AI-augmented software development, enabling better alignment between human and AI mental models. Reladraw can be installed via npm, and the project repository includes a reference example of an architecture diagram drawn both by hand and via Reladraw syntax. Unlike other existing diagram languages that hand arrangement over to an automated layout engine, Reladraw lets users directly control where each element is placed.

hackernews · jpwalsh234 · Sep 26, 17:10

**Background**: Existing diagramming solutions fall into two main categories: text-based auto-placement tools like Mermaid and Graphviz, which handle layout automatically but do not let users control the final appearance of the diagram, and GUI-based drag-and-drop tools like Draw.io, which give full layout control but are time-consuming to work with and difficult for AI agents to manipulate programmatically. Mermaid is a popular open-source text-based diagramming tool created in 2014, while Graphviz is an older open-source tool for rendering graphs from text-based DOT language descriptions.

## [Hackers sell cheap access to top AI models on dark web](https://www.ft.com/content/3f406fbe-b72e-488f-9975-5b94e95dfe32) ⭐️ 7.0/10

The Financial Times reports that hackers are selling stolen access to popular AI models from Anthropic, Google, and OpenAI at prices as low as 3% of the official cost on the dark web. Some state-backed hacking organizations are also hijacking cloud computing resources to run AI models for malicious activities. This illegal trade highlights a rapidly growing emerging cybersecurity threat tied to large language models, and it calls for urgent attention and response from the global cybersecurity and AI industries. The availability of cheap access to powerful AI models lowers the barrier for cybercriminals and state actors to carry out large-scale malicious activities like ransomware, espionage, and offensive operations. The 3% price refers to a discount relative to the official pricing of the AI model access, meaning hackers sell access for just 3% of what a legitimate user would pay. Google threat intelligence analysts have verified this illegal trading activity, which focuses on the most powerful commercial large language models that are typically expensive to access legitimately.

**Background**: Anthropic is a leading American AI research company founded in 2021 by former OpenAI employees, focused on AI safety and development of the large language model Claude. A state-backed hacking organization is a hacking group that receives support from a national government, typically conducting cyber activities to advance that nation's strategic interests, including espionage and disruptive attacks. AI model access credentials such as API keys are used to authenticate and authorize access to commercial large language models, which are often sold illegally after being stolen by hackers.

## [Open source harness fix makes DeepSeek outperform Opus 4.7](https://rss.bz/zh/post/deepseek-tool-calling-harness-fix?source=telegram) ⭐️ 7.0/10

Developer Ahmad Awais has open sourced a CLI harness fix that adds a tool input correction layer for DeepSeek, allowing DeepSeek v4 Pro to outperform Claude Opus 4.7 on internal tool calling evaluations. This improvement demonstrates that open source community modifications can close performance gaps between leading LLMs on the critical task of tool calling, which is foundational for building AI agents and automated workflows. It also offers a more cost-effective alternative to Claude Opus 4.7 for tool-heavy use cases. DeepSeek v4 Pro is a 1.6T total parameter Mixture-of-Experts model with 49B activated parameters and 1 million token context, and it is already known to rival GPT-5.5 and Claude Opus 4.7 at a much lower cost.

**Background**: Tool calling is a core capability of modern large language models that enables them to interact with external functions, APIs, and software to complete complex tasks. A harness in this context refers to a lightweight command-line interface framework that facilitates testing and interaction with LLMs, including supporting tool calling functionality. Claude Opus 4.7 is Anthropic's top-tier large language model released in April 2026, known for strong performance in coding and complex instruction following.
