## [OpenAI 在 API 上线 GPT-Live-1](https://openai.com/index/introducing-gpt-live-1-in-the-api/) ⭐️ 9.0/10

OpenAI 于 2026 年 9 月 10 日在面向开发者的 API 中上线了全双工可同时听说的模型 GPT-Live-1。该模型在 Full Duplex Bench 基准测试上比上一代 GPT-Realtime-2.1 性能高出 30%，API 访问前端语音层的定价为每分钟 0.05 美元。 本次发布推动了低延迟实时语音人工智能应用的开发，让开发者能够构建更自然的交互式语音智能体，应用于客服、语言学习、电话服务等场景。它标志着全双工语音人工智能商业化迈出重要一步，对开发者和终端用户都将产生积极影响。 GPT-Live-1 将语音理解和输出整合到单个模型中，消除了传统语音转文字、大语言模型、文字转语音分模块衔接带来的延迟，同时支持自然打断、背景噪声处理、长对话，还可以将复杂推理和工具调用交给后端模型处理。早期采用者已经验证了其在用户体验和开发效率上的显著提升，例如某语言学习平台的误打断次数减少了 80%，某医疗服务平台的代码量减少了 80%。

telegram · AI_News_CN · Sep 11, 03:17

**背景**: 全双工语音指语音对话系统能够在输出语音的同时同步理解输入语音，相较于一次只能听或说的传统半双工系统，全双工系统支持更自然的对话行为，比如打断、重叠对话和动态话轮转换。Full Duplex Bench 是一个开放的标准化基准测试框架，用于评估全双工口语模型的交互对话能力，核心测试指标包括暂停处理、打断管理、话轮转换以及多轮对话中的任务表现。

## [Trynix.dev 可在浏览器运行任意 Nix 包](https://simonwillison.net/2026/Sep/10/trynix/) ⭐️ 8.0/10

Farid Zakaria 推出了 trynix.dev，这是一个基于 WebAssembly 的服务，允许用户直接在浏览器中运行过去 13 年的任意 Nix 软件包。该服务还支持一个 GitHub 动作，允许用户无需任何服务器基础设施，直接在浏览器中启动并测试拉取请求构建。 该工具消除了测试特定版本 Nix 软件包或拉取请求构建时对本地环境配置的需求，让开发人员可以更轻松地快速测试代码。它还展示了 Nix 包管理、WebAssembly 和浏览器内虚拟化的新颖结合，拓展了基于浏览器的开发工具的能力边界。 Trynix.dev 使用 qemu-wasm 项目，通过 WebAssembly 在浏览器中完整运行一个 x86_64 架构的 Linux 虚拟机。任意可用的 Nix 软件包都可以通过 URL 参数指定加载，用户点击加载按钮后即可获得一个交互式 shell 来使用该软件包。

rss · Simon Willison · Sep 10, 23:44

**背景**: Nix 是一个纯函数式跨平台包管理器，支持可重复的软件包构建，并能让不同版本的软件包相互隔离。QEMU 是一款流行的开源机器模拟器和全系统虚拟化工具，支持在宿主机系统上运行完整的操作系统，而 qemu-wasm 是一个被编译为 WebAssembly 的实验性 QEMU 移植版本，可让它在浏览器中运行。
