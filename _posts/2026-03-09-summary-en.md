## [Tsinghua's Xingyan AI Boosts JWST Observation Depth](https://www.aibase.com/zh/news/26011) ⭐️ 8.0/10

Researchers from Tsinghua University developed an AI astronomy large model named Xingyan that boosts the James Webb Space Telescope's detection depth by 1 magnitude. The team identified over 160 candidate high-redshift galaxies from the cosmic dawn era using Xingyan, which is three times the number of such galaxies previously discovered, and the research has been published in the journal Science. This breakthrough demonstrates the transformative value of interdisciplinary AI for Science research and expands the boundaries of deep space observation, providing precious new data for studying the origin and early evolution of the universe. It also proves that artificial intelligence can significantly enhance the scientific output of existing top-tier astronomical observation facilities. The Xingyan model solves the problem of high-fidelity photon reconstruction under extremely low signal-to-noise ratio, by reconstructing 2D deep space images into 3D spatiotemporal volumes and using a unique photometric adaptive screening mechanism to separate noise from target galaxy signals. It improves JWST's detection accuracy by 1.6 magnitudes in addition to the 1 magnitude gain in detection depth.

telegram · AI_News_CN · Mar 9, 01:10

**Background**: Cosmic dawn refers to the period between 200 million and 500 million years after the Big Bang, when the first generation of galaxies formed in the early universe. The James Webb Space Telescope is currently the most powerful space observatory for studying the early universe, but its detection of extremely faint distant galaxy signals is limited by background noise from sky glow and the telescope's own thermal radiation. Signal-to-noise ratio measures the proportion of useful target signal relative to interference noise, and lower values mean target signals are harder to distinguish from noise.

## [Agent Safehouse: macOS Sandbox for Local AI Agents](https://agent-safehouse.dev/) ⭐️ 7.0/10

Developer eugene1g has released Agent Safehouse, a new dependency-free, macOS-native tool that generates sandbox-exec policies to securely isolate locally running AI agents. The tool was shared and discussed on Hacker News, earning significant positive community attention. This tool addresses a growing need for secure local execution of AI coding agents, which can otherwise access or modify sensitive files on a user's machine without restriction. It enables developers to run local AI agents safely without relying on heavy virtualization or remote containers, filling a gap for macOS-based developers working with local AI tools. Agent Safehouse is a lightweight policy generator for macOS's built-in sandbox-exec tool, with zero external dependencies and no virtualization required, using kernel-level deny-first permission enforcement. It restricts AI agents to only access the specific files and permissions they need to operate, limiting potential damage from untrusted or misbehaving agent actions.

hackernews · atombender · Mar 8, 20:30

**Background**: Local AI agents are AI tools that run directly on a user's personal computer rather than on a remote cloud server, which many developers prefer for privacy and performance reasons. Sandboxing is a common security technique that isolates running processes from the rest of the system, limiting the damage a compromised or misbehaving process can cause. sandbox-exec is a built-in command-line sandboxing tool for macOS that uses custom Scheme-like syntax to define process permission policies.

## [GBL Flaw Unlocks Snapdragon 8 Elite Gen 5 Bootloader](https://www.cnblogs.com/hicode002/p/-/unlock-your-qualcomm) ⭐️ 7.0/10

Security researchers disclosed a GBL vulnerability in Qualcomm's flagship Snapdragon 8 Elite Gen 5 SoC that enables bypassing signature verification to permanently unlock the device bootloader. Exploiting this vulnerability requires physical access to the target device via 9008 mode or a hardware programmer. This vulnerability enables permanent bootloader unlocking on Qualcomm's latest flagship SoC that was previously restricted by manufacturers, impacting both Android ecosystem security and the Android modding community. It also reveals a critical security gap in the new GBL boot architecture adopted by modern Android flagship devices. The flaw exists because the Android Bootloader (ABL) does not enable UEFI secure boot verification when loading GBL from the efisp partition, allowing attackers to implant custom UEFI applications to gain EL1 privilege code execution. Public proof-of-concept exploits for this vulnerability carry the risk of damaging the device's TEE and disabling biometric functions.

telegram · zaihuapd · Mar 8, 07:36

**Background**: Generic Bootloader (GBL) is a UEFI-based boot application developed by Google for Android, designed to reduce vendor-specific bootloader modifications and unify the Android boot flow. Qualcomm 9008 mode, also called QDLoader mode, is a low-level emergency download mode for Qualcomm-based devices that allows direct firmware flashing even when the main system cannot boot. Trusted Execution Environment (TEE) is an isolated secure area on a mobile processor that protects sensitive operations and data such as biometric credentials separate from the main operating system.
