A new article put forward the Cognitive Dark Forest hypothesis, which claims that publicly sharing new ideas risks having them absorbed into large language model training data, erasing creators' first-mover advantages from novel thinking. This hypothesis has triggered wide-ranging debate on Hacker News. This hypothesis raises pressing questions about open knowledge sharing and individual innovation in the age of generative AI, which could change how creators and inventors choose to disclose their original work. It touches on core tensions between open collaboration and individual intellectual incentive in the AI era. The hypothesis specifically argues that the act of sharing an out-of-the-box idea expands the capability of existing LLMs, which can then replicate the idea far faster than traditional competitors could. Some critics note that current LLMs do not learn new content on the fly after their initial training is completed.

The original concept has since been adapted to many other domains beyond astronomy to describe strategic risks of public visibility.

## [Pretext: DOM-free text height calculation library](https://simonwillison.net/2026/Mar/29/pretext/#atom-everything) ⭐️ 7.0/10

Former React core developer Cheng Lou has released Pretext, a new lightweight JavaScript browser library that calculates the height of line-wrapped paragraphs without accessing the DOM. This approach delivers dramatically faster performance than the traditional DOM-based measurement method. 该库解决了前端开发中长期存在的性能瓶颈，传统文本高度测量会触发开销极高的DOM重排与布局重计算。它可以实现此前难以落地的全新高性能动态文本渲染与布局效果。 Pretext works by running an initial expensive `prepare()` step that caches measured text segment widths via an offscreen canvas, then uses cached data in repeated fast `layout()` calls to calculate wrapped text height. The tiny (only a few kilobytes) library supports all major languages including RTL scripts, non-Latin character sets, and emojis, and is tested against full-length public domain books including non-English texts to confirm accuracy against browser native layout.

rss · Simon Willison · Mar 29, 20:08

**Background**: Traditionally, to calculate the final height of line-wrapped text in a web browser, developers need to render the text to the DOM first then measure its rendered dimensions. This process triggers a DOM reflow, which is computationally expensive and can cause performance issues especially when done repeatedly for dynamic content. Cheng Lou, the creator of Pretext, is a former core developer of the React frontend framework and the original creator of the popular react-motion animation library.
