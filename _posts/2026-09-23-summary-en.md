## [vLLM v0.30.0 major release announced](https://github.com/vllm-project/vllm/releases/tag/v0.30.0) ⭐️ 8.0/10

The vllm-project has released vLLM version 0.30.0, a new update that adds support for multiple new large language models and introduces a persistent weight cache to speed up engine restarts. This release includes 762 commits from 315 contributors, 104 of whom are new to the project. As a widely used open-source LLM inference engine, this release brings significant performance improvements and expanded model compatibility that benefits both developers and production deployers of large language models. It strengthens vLLM's position as a leading choice for high-performance LLM serving by incorporating community contributions and new optimization technologies. Notable updates include new watermarking functionality for LLM outputs, improved sparse KV cache handling for better GPU memory management, and extensive performance optimizations for popular models like Qwen3.8-Flash-Next and Kimi K3. The new persistent weight cache allows engines to reuse post-quantized, tensor-parallel weights from GPU memory via CUDA IPC instead of reloading from disk, cutting down restart time significantly.

**Background**: vLLM is an open-source high-performance, memory-efficient inference engine for large language models originally developed by the Sky Computing Lab at UC Berkeley. It has become one of the most popular tools for running and serving LLMs due to its efficient memory management and high throughput. FlashMLA is DeepSeek's optimized attention kernel library that powers DeepSeek's latest large language models, enabling more efficient attention computation.
