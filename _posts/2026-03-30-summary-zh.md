## [Pretext：无需 DOM 的文本高度计算库](https://simonwillison.net/2026/Mar/29/pretext/#atom-everything) ⭐️ 7.0/10

前 React 核心开发者 Cheng Lou 发布了全新轻量 JavaScript 浏览器库 Pretext，它可以在不访问 DOM 的情况下计算折行段落的高度，性能比传统基于 DOM 的测量方法快得多。 该库解决了前端开发中长期存在的性能瓶颈，传统文本高度测量会触发开销极高的 DOM 重排与布局重计算。它能够实现过去难以落地的全新高性能动态文本渲染和布局效果。 Pretext 的工作原理是先运行一次开销较高的`prepare()`步骤，通过离屏画布测量并缓存文本片段的宽度，之后就可以在多次快速调用`layout()`时使用缓存数据计算折行文本高度。这个库体积非常小，仅数千字节，支持所有主流语言，包括从右向左书写的文字、非拉丁字符集和 emoji，还通过对照全本公共领域图书（包括多份非英文文本）进行测试，确保计算结果和浏览器原生布局一致。

rss · Simon Willison · Mar 29, 20:08

**背景**: 在传统方案中，开发者要想计算网页中折行文本的最终高度，需要先把文本渲染到 DOM 中，再测量它的渲染尺寸。这个过程会触发 DOM 重排，计算开销很高，尤其是需要对动态内容反复计算时，很容易引发性能问题。Pretext 的作者 Cheng Lou 是 React 前端框架的前核心开发者，也是知名动画库 react-motion 的原创作者。
